# Thử tạo organization ruleset — 09/10/2026

- Organization API xác nhận `plan.name = free`.
- `terraform fmt -check` và `terraform validate`: thành công.
- `terraform plan`: `1 to add, 0 to change, 0 to destroy`; mục tiêu là `github-org-iac` và `repository-demo`, nhánh mặc định.
- `terraform apply` với plan đã lưu: GitHub trả `POST https://api.github.com/orgs/xbrain-org-poc/rulesets: 404 Not Found`.
- Sau apply: `terraform state list` rỗng; API ruleset của `github-org-iac` trả `[]`. Không có organization ruleset nào được xác nhận là đã tạo.

GitHub Docs yêu cầu gói Team/Enterprise để tạo ruleset cấp org: https://docs.github.com/en/organizations/managing-organization-settings/creating-rulesets-for-repositories-in-your-organization. Token CLI lúc thử thiếu scope `admin:org`; kết quả 404 vì vậy không dùng riêng để kết luận nguyên nhân duy nhất là gói Free.
