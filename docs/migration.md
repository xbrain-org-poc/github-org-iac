# Ghi chú chuyển sang repo IaC chung

- Code và evidence được **sao chép** từ ba repo PoC; repo cũ giữ nguyên để các link trong Jira và lịch sử demo tiếp tục truy cập được.
- Ban đầu, bốn resource repository được chuyển vào `repositories/sandbox/` với state local. Sau đó, state được tách thành hai root mang tên repo: [`repository-demo/`](../live/xbrain-org-poc/repositories/repository-demo/) và [`iac-repository-management-poc/`](../live/xbrain-org-poc/repositories/iac-repository-management-poc/). Mỗi root sở hữu repository và ruleset tương ứng; địa chỉ resource trong từng state được giữ nguyên. Bản sao state trước khi tách được lưu cục bộ, không commit. Không chạy `apply` từ code/state PoC cũ.
- Người clone repo mới không nhận được state local. Trước khi `plan/apply`, import các GitHub resource đang tồn tại theo hướng dẫn của từng root: [repo demo](../live/xbrain-org-poc/repositories/repository-demo/docs/huong-dan-chay.md) và [repo PoC ban đầu](../live/xbrain-org-poc/repositories/iac-repository-management-poc/docs/huong-dan-chay.md); đối chiếu ID ruleset hiện tại từ GitHub API.
- `identity/` không có active membership trong state cuối PoC; không sao chép state cũ. Chỉ thêm username đã được chấp thuận vào tfvars local sau khi kiểm tra org hiện tại.
- `access/` nhận code Team từ [`github-org-iac-po` tại `85a99fb`](https://github.com/phuc-do-v2/github-org-iac-po/tree/85a99fb), cùng tests, research, báo cáo và workbook. Giữ nguyên địa chỉ `github_team.root`, `github_team.child`, `github_team_membership.member` và read-only data source. State cuối PoC trống sau cleanup nên không sao chép state hoặc tfvars. Tích hợp này không chạy live apply mới; [evidence](../live/xbrain-org-poc/access/docs/jira-task-b-live-evidence-vi.md) thuộc lần chạy ngày 01/10/2026.
- Chạy Terraform riêng tại `access/` theo [README](../live/xbrain-org-poc/access/README.md). Nếu team/membership đã tồn tại sau PoC, import theo [runbook](../live/xbrain-org-poc/access/RUNBOOK.md) trước khi apply; không import cùng object vào hai state hoặc chạy hai repo cùng quản lý một object. Sample `terraform.empty.tfvars.example` mô tả trạng thái đích cuối nhưng sẽ đề xuất destroy nếu state đang sở hữu tài nguyên.
- `identity/` sở hữu organization membership; `access/` chỉ kiểm tra org member active và quản lý direct team membership. `github_team_repository` chưa có trong PoC Team, cần thống nhất owner/state trước khi thêm.
- `org-policies/` là Terraform root riêng. Ruleset cấp org được khai báo nhưng chưa tạo được vì org đang dùng GitHub Free; không chia sẻ state với `repositories/`.
- Pipeline PR plan/apply cần remote backend có locking, credential giới hạn quyền và chính sách approval. Thư mục workflow hiện chỉ ghi trạng thái này, chưa tự động thực thi.
